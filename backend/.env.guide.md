# 环境变量配置指南

## 开发环境配置

### 1. 复制环境变量文件

```bash
cd backend
cp .env.example .env
```

### 2. 配置 PostgreSQL 数据库

#### 方式 A: 使用 Docker (推荐)

确保已安装 Docker Desktop 或 Docker Engine：

```bash
# 启动 PostgreSQL 容器
docker-compose up -d

# 验证容器运行状态
docker ps

# 查看数据库日志
docker-compose logs -f
```

使用默认配置即可：
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=english_ai
DB_USER=postgres
DB_PASSWORD=postgres
```

#### 方式 B: 本地 PostgreSQL

如果本地安装了 PostgreSQL：

1. 创建数据库：
```bash
createdb english_ai
```

2. 或在 psql 中执行：
```sql
CREATE DATABASE english_ai;
```

3. 配置环境变量：
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=english_ai
DB_USER=你的数据库用户
DB_PASSWORD=你的数据库密码
```

### 3. JWT 密钥配置

**必须修改**默认 JWT Secret（生产环境）：

```bash
# 生成随机密钥
openssl rand -base64 32
```

更新 `.env`：
```env
JWT_SECRET=你的随机密钥
JWT_EXPIRES_IN=7d
```

### 4. OpenAI API 配置（可选）

如果需要 AI 功能：

1. 获取 API Key：https://platform.openai.com/api-keys
2. 更新 `.env`：
```env
OPENAI_API_KEY=sk-your-openai-api-key-here
OPENAI_MODEL=gpt-4
```

### 5. 前端地址

开发环境默认：
```env
FRONTEND_URL=http://localhost:5173
```

生产环境修改为实际域名：
```env
FRONTEND_URL=https://your-domain.com
```


## 常见问题

### 1. 数据库连接失败

**错误**: `ECONNREFUSED`

**解决**:
- Docker: `docker-compose up -d`
- 本地：`brew services start postgresql` 或 `sudo service postgresql start`

### 2. 认证失败

**错误**: `password authentication failed`

**解决**: 检查 `DB_USER` 和 `DB_PASSWORD` 是否正确

### 3. 端口已被占用

**错误**: `EADDRINUSE`

**解决**: 修改 `PORT` 或停止占用端口的进程
```bash
lsof -i :3001
kill <PID>
```

### 4. JWT 密钥过长/过短

**解决**: 使用推荐的生成方式，确保密钥安全且长度合适

## 生产环境注意事项

1. **数据库**: 使用独立的 PostgreSQL 实例，不要使用默认密码
2. **JWT Secret**: 必须使用强随机密钥
3. **环境变量**: 使用环境管理工具（如 AWS Parameter Store, HashiCorp Vault）
4. **HTTPS**: 强制使用 HTTPS
5. **CORS**: 限制为实际前端域名
6. **日志**: 调整日志级别为 `info` 或 `warn`
